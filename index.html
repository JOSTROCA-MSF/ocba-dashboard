    Data Quality, Methodology & Limitations
    Methodology & Calculation Rules

    All data is sourced from the imported worksheet, prioritizing OCBA Summary when available. The importer now supports the original matrix layout used in the uploaded file.

    Metric Identifier Formula / Calculation Method Original Source Definition
    Accumulated Users Latest selected month value in Total Users (accumulated) Cumulative number of users since the platform launched.
    Monthly Active Users Sum and arithmetic mean of selected Unique Users/Month Number of distinct users who accessed the platform during the month.
    Total Interactions Sum of selected Interactions/Month Total number of user interactions recorded during the month (1 interaction = 1 question).
    Interactions / User Total Interactions / Sum of Monthly Active Users Derived measurement of engagement depth per user.
    HQ / Field Split Mean of HQ Users (%) and Country Programs Users (%) Percentages of users based at HQ vs field operations.
    Data Limitations & Excluded Metrics

    * Omitted Usability Standard Metrics: Task completion rates, task duration/time-on-task, SUS scores, and error counts are not present in the source workbook.
    * Qualitative Feedback: No free-text feedback columns are imported by this dashboard.
    * Data Anonymization: The dashboard works with aggregated metrics only.
